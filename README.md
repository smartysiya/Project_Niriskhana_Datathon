# NIRIKSHANA (ನಿರೀಕ್ಷಣ)  
### Government of Karnataka | Karnataka State Police (KSP)
### State Crime Records Bureau (SCRB) — Enterprise Intelligence & Analytics Platform

**NIRIKSHANA** is an official, enterprise-grade AI-driven crime intelligence, spatial analytics, and criminological platform built specifically for Karnataka State Police (KSP) and the State Crime Records Bureau (SCRB).

##  Enterprise Government UI/UX Architecture

- **Primary Color Palette**: KSP Navy (`#1E3A5F`), Secondary Indigo (`#5B4BB7`), Accent Blue (`#2563EB`), Crisp Light Background (`#F5F7FA`), White Card Surfaces (`#FFFFFF`), Border Gray (`#E5E7EB`).
- **Brand Identity**: Custom NIRIKSHANA **Eye + Map Pin** SVG Logo representing active vigilance and spatiotemporal intelligence.
- **Language Support**: Instant toggle between **English (`NIRIKSHANA`)** and **Kannada (`ನಿರೀಕ್ಷಣ`)**.
- **Header & Navigation**: Single, clean top sub-header (`Government of Karnataka | Karnataka State Police | State Crime Records Bureau (SCRB)`), followed by structured horizontal navigation (`Dashboard`, `Crime Map`, `Hotspots`, `Network Analysis`, `Risk Matrix`, `Socio-Economic Insights`, `Reports`, `Settings`).
- **Enterprise KPI Cards**: Soft shadow (`shadow-sm`), 8-10px border radius, thin border `#E5E7EB`, clean numbers with trend indicators.
- **Toolbar Filter Bar**: Search input, District dropdown, Shift/Time Window dropdown, Crime Type dropdown, and Reset Filters button.

---

##  Technology Stack

- **Frontend**: React 18, Vite, Tailwind CSS (Custom KSP Enterprise Palette), Leaflet.js, SVG Node Graph Renderer, Axios.
- **Serverless Backend**: Node.js 18 (Express) on **Zoho Catalyst Advanced I/O Functions**.
- **Database**: **Zoho Catalyst Relational Data Store (ZCQL)** managing 5 core tables (`District`, `Unit`, `CrimeSubHead`, `CaseMaster`, `Accused`).
- **Deployment Platform**: 100% Serverless on Zoho Catalyst Infrastructure.
